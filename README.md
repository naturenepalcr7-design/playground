# KMC-GIS-SERVER

WebGIS & Field Mapping Tasking Manager with geofenced data collection.

## Quick Start

```bash
docker compose up --build
```
Exposed port: 80 (HTTP)

Access the server at:
- Web App: `http://103.69.126.226` (or `http://localhost`)
- API Docs: `http://103.69.126.226/api/docs`
- OGC API: `http://103.69.126.226/ogc`
